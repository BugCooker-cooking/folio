# Folio

A quiet, native place to read and write.

## What it does

Folio opens the files you actually work with and stays out of the way.

- Markdown, JSON, SQL, and plain text
- Java, Python, JavaScript, Go, Rust, Swift, and more
- Native find and replace, line numbers, and live counts
- Seven interface languages, following the system

> Good tools should feel quiet. The content is the interface.

## Three ways to read Markdown

| Mode | Best for |
| --- | --- |
| Read | A calm, styled reading view |
| Split | Source and preview, side by side |
| Source | The raw Markdown only |

## A small sample
