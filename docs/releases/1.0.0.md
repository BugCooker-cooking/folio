Folio 1.0 is the first public release: a focused native editor for the files you actually open.

## Download

**Folio-1.0.0-macOS-universal.zip** — universal build for Apple Silicon and Intel.

SHA-256:

```text
cfefae88137d8ae62fce4f1ba31e9ba9bfbd686235b8ff958b3e0df16e11ba17
```

Requirements: **macOS 14 or later**.

1. Download and unzip the archive.
2. Move `Folio.app` to **Applications**.
3. The build is ad-hoc signed and not notarized. If macOS blocks the first launch, Control-click the app and choose **Open**.

## Highlights

- Native SwiftUI and AppKit editor with undo, find, drag-and-drop, recent files, and unsaved-change prompts.
- Markdown opens in a styled reading view. **Edit** enters a live source + preview split; the header switches between Source, Split, and Preview.
- Markdown toolbar for headings, bold, italic, strikethrough, inline code, code blocks, links, lists, quotes, tables, and horizontal rules.
- JSON validation, formatting, and minification without changing key order, with distinct colors for keys, strings, numbers, booleans, and `null`.
- SQL and code highlighting for Java, Kotlin, Scala, Python, JavaScript/TypeScript, C/C++, C#, Go, Rust, Ruby, PHP, Swift, Shell, HTML/XML/SVG, CSS/SCSS/LESS, YAML, and TOML.
- Selecting text highlights every matching occurrence in the document.
- Seven interface languages following the system; light, dark, and system appearance.
- UTF-8/UTF-16/Latin-1 detection, BOM preservation, and original line endings.
- A new layered folio-pages icon and a matching welcome mark.
- Universal binary for Apple Silicon and Intel.

## Known limitations

- Syntax highlighting is lexical, not semantic. There is no LSP, completion, diagnostics, terminal, or project tree.
- Markdown preview covers core syntax; embedded HTML and MDX are shown as source.
- Single window with open documents in the sidebar; no tabs or multiple windows.
- Saves are explicit; there is no autosave.
- The downloadable app is ad-hoc signed, not notarized.
