# Changelog

## 1.0.0 — 2026-10-24

The first public release of Folio.

- Native SwiftUI + AppKit editor with no third-party dependencies
- Styled Markdown reading mode, source/preview split, and a formatting toolbar
- JSON validation, formatting, minification, and type-aware colors
- Lexical syntax highlighting for SQL and 20 common source languages
- Selection-match highlighting, regex find and replace, line numbers, and live counts
- Encoding, BOM, and line-ending preservation
- Seven interface languages following the system language
- Light, dark, and system appearance; localized hover tips
- Developer ID signed and notarized universal macOS build for Apple Silicon and Intel, distributed as DMG and ZIP

See the detailed [1.0.0 release notes](docs/releases/1.0.0.md).
